A collection of digital design projects focused on RTL development, simulation, and hardware design fundamentals. This repository includes arithmetic circuits, data-handling modules, and other digital systems, with room to grow as new projects are added.
Projects
- FIFO: A First-In, First-Out buffer for storing and retrieving data in order.
- Booth Multiplier: A multiplier based on Booth’s algorithm for signed binary multiplication.
- Serial Multiplier: A sequential multiplier that computes a product over multiple clock cycles.
Tools and Languages
Projects may use Verilog or SystemVerilog and can be simulated with a compatible HDL simulator. Add the specific language version, simulator, synthesis tools, and board details as applicable.
Running a Project
Refer to the instructions inside each project folder for setup and simulation steps. Commands and required tools may differ between projects.
